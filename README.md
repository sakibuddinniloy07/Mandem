# MANDEM — Men's Apparel

A full-stack Next.js (App Router) e-commerce storefront for MANDEM, built
monochrome/concrete to match the brand's hero art. Product browsing, cart,
checkout with bKash + Cash on Delivery, and order tracking all work
end-to-end out of the box.

## Stack

- Next.js 16 (App Router, TypeScript, Tailwind v4)
- Zustand for cart state (persisted to localStorage)
- Supabase (Postgres) for live inventory + order storage
- bKash Checkout (Tokenized) for payments

## Getting started

```bash
npm install
npm run dev
```

The store works immediately with no setup: product catalog and stock
estimates are seeded from `src/data/products.json`, and orders are kept
in-memory for the current server process (COD works fully; bKash shows a
clear "not configured" message until you add credentials).

## Connecting Supabase (live inventory + persisted orders)

1. Create a Supabase project (or use an existing one).
2. Run `supabase/schema.sql` against it (SQL Editor, or `supabase db push`).
3. Copy `.env.example` to `.env.local` and fill in `SUPABASE_URL` /
   `SUPABASE_SERVICE_ROLE_KEY`.
4. Seed live stock: `SUPABASE_URL=... SUPABASE_SERVICE_ROLE_KEY=... node scripts/seed-stock.mjs`

Once set, orders and stock decrements are fully persisted in Postgres.

## Connecting bKash

1. Get sandbox (then live) credentials from https://developer.bka.sh.
2. Fill in `BKASH_*` vars in `.env.local`. `BKASH_CALLBACK_URL` must be a
   publicly reachable URL once deployed (bKash redirects the customer's
   browser back to it).
3. Test end-to-end in the sandbox before going live.

## Product images

Product photography is placeholder original vector artwork (generated by
`scripts/run-generate.mjs`) in the brand's monochrome palette — swap in real
product photos at `public/products/<slug>-1.svg` / `-2.svg` (any image
format works, just update the extension in `src/lib/seed-data.ts`).

## Project structure

- `src/app` — routes (home, shop, product, cart, checkout, orders, API routes)
- `src/components` — UI, layout, product, cart, shop components
- `src/lib` — cart store, orders repository, bKash client, Supabase clients,
  catalog/seed data, shipping & formatting helpers
- `supabase/schema.sql` — database schema + RLS policies
- `scripts/` — product art generator, Supabase stock seeder
